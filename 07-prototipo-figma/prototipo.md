# Protótipo no Figma

Protótipo navegável das principais telas do sistema, mostrando a organização e o fluxo de navegação.

**Link do protótipo:** [https://www.figma.com/proto/lZXzgyLHeS56aJhtOmAyjq/Academia-de-Ginastica?node-id=2-2&p=f&t=laFl1Qo7nfo1MP8y-1&scaling=min-zoom&content-scaling=fixed&page-id=0%3A1](https://www.figma.com/proto/lZXzgyLHeS56aJhtOmAyjq/Academia-de-Ginastica?node-id=2-2&p=f&t=laFl1Qo7nfo1MP8y-1&scaling=min-zoom&content-scaling=fixed&page-id=0%3A1)

## Como navegar

1. Abra o link e clique em **Present** (modo de apresentação).
2. Na tela de **login**, escolha o perfil que deseja simular (Administrador, Secretaria, Instrutor ou Aluno). No sistema real, o perfil é definido pela conta do usuário.
3. Cada perfil abre um menu diferente. Navegue pelos botões.

## Telas

| Tela | Perfil |
|---|---|
| Login | todos |
| Menu principal | um menu para cada perfil |
| Cadastro de aluno | Administrador, Secretaria |
| Cadastro de instrutor | Administrador |
| Cadastro de turma | Administrador |
| Matrícula e monitor | Administrador, Secretaria, Instrutor |
| Registro de ausências | Administrador, Secretaria, Instrutor |
| Minhas turmas e faltas | Aluno |
| Relatório de ausências | Administrador, Secretaria |

As telas descritas campo a campo estão em `06-interfaces/interfaces.md`.
