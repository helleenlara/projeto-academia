Atividade Formativa — UniRuy Wyden

## Premissas adotadas

- O aluno monitor deve estar matriculado na turma que monitora.
- As ausências são registradas por data; o total é calculado pela contagem.
- O sistema é web responsivo, com banco de dados MySQL.
- Quatro perfis de acesso: Administrador, Secretaria, Instrutor e Aluno, com permissões atribuídas pelo administrador.
